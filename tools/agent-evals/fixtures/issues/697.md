# [Bug]: useStoryblokBridge declared in rsc.d.ts but not exported from rsc.js / rsc.mjs in @storyblok/react@7.2.0

### Package

@storyblok/react

### Bug Description

@storyblok/react@7.2.0's /rsc entry point declares `useStoryblokBridge` in its type definitions but
doesn't actually re-export it at runtime causing `TypeError: useStoryblokBridge is not a function`
in any client component using it.

### Steps to Reproduce

```ts
"use client";
import { useStoryblokBridge } from "@storyblok/react/rsc";

export function MyClientComponent({ story }) {
  useStoryblokBridge(story.id, (newStory) => {
    /* ... */
  });
  // ⨯ TypeError: useStoryblokBridge is not a function
}
```

_No response_

### Expected Behavior

`useStoryblokBridge` should be exported at runtime from rsc.js and rsc.mjs, matching the .d.ts
declaration and the behavior of the other entry points.

### Actual Behavior

run time crashes
