A client-rendered Vue app (Vite) that renders Storyblok stories with `@storyblok/vue`
(https://www.storyblok.com/docs/packages/storyblok-vue). `src/PageView.vue` fetches the story for the path, `home` for `/`. Register every new block in `src/main.js`.

- Vue: https://vuejs.org/llms.txt
- Vite: https://vite.dev/llms.txt

`npm run dev` serves https://localhost:5173. The Visual Editor needs HTTPS.
