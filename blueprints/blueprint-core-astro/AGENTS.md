An Astro site with server rendering that renders Storyblok stories with `@storyblok/astro`
(https://www.storyblok.com/docs/packages/storyblok-astro). Blocks live in `src/storyblok/`. Register every new block in `astro.config.mjs`.

- Astro: https://docs.astro.build/en/getting-started/

`npm run dev` serves https://localhost:4321. The Visual Editor needs HTTPS.
