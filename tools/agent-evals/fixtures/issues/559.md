# [Bug]: Non-function value encountered for default slot. Prefer function slots for better performance.

### Package

@storyblok/nuxt

### Bug Description

When parsing links from richtext as NuxtLink component with the guide from:
https://www.storyblok.com/docs/libraries/js/nuxt-sdk#example-custom-link-with-nuxtlink The console
get's a warning for every link: "[Vue warn]: Non-function value encountered for default slot. Prefer
function slots for better performance." It comes from the 0 of this line:
`return [asTag(NuxtLink), { to: HTMLAttributes.href }, 0]` The 0 is for the value inside the link.
So the text which has to be rendered. So there must be a way to write something like this to don't
get the warning anymore: `return [asTag(NuxtLink), { to: HTMLAttributes.href },  () => 0]` But that
doesn't work. In the old richtext API I could make this: `() => node.text` But now with the changed
API it seems that the only way to access the text inside the link is to use this 0. But there has to
be a solution to output the link-text while using it in a function.

### Steps to Reproduce

1. create storyblok space and create page with links inside richtext element
2. fetch this richtext with the @storyblok/nuxt package inside Nuxt frontend
3. use this guide to parse links as NuxtLinks component:
   https://www.storyblok.com/docs/libraries/js/nuxt-sdk#example-custom-link-with-nuxtlink
4. see warnings in console

Code-Snippets from official documentation should not throw warning because not using a function
Something like this should work: `return [asTag(NuxtLink), { to: HTMLAttributes.href },  () => 0]`

### Actual Behavior

works without function: `return [asTag(NuxtLink), { to: HTMLAttributes.href }, 0]`
