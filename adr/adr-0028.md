# ADR-0028: Name ADRs by Number Only

**Status:** Accepted  
**Date:** 2026-11-18

## Context

ADRs were named `NNNN-slug.md`. Two PRs open at the same time could both take the next free number:
their files differed by slug, so Git merged both without a conflict. ADR-0017 and ADR-0022 each
exist twice as a result.

A CI check for duplicate numbers can't prevent this. Required checks don't rerun when `main` moves,
so two PRs that both pass can still merge the same number.

## Decision

New ADRs are named `adr/adr-NNNN.md`, numbered after the highest existing ADR. `adr/INDEX.md` lists
every ADR with a short description.

Two PRs that take the same number add the same file, so Git blocks the second merge with a conflict,
whether or not the branch is up to date.

## Consequences

- File names no longer describe the ADR; `adr/INDEX.md` does.
- Parallel PRs that add ADRs also conflict in `adr/INDEX.md`, even with different numbers. Resolving
  it means keeping both lines.
- Existing ADRs keep their names, since other files reference them.
