# AGENTS.md

A Nuxt app with server rendering that renders Storyblok stories with `@storyblok/nuxt`
(https://www.storyblok.com/docs/packages/storyblok-nuxt). Blocks in `app/storyblok/` are registered automatically by `@storyblok/nuxt`.

- Nuxt: https://nuxt.com/llms.txt

`npm run dev` serves https://localhost:3000. The Visual Editor needs HTTPS.
