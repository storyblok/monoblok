# Website: content migrations demo

Demo only, not meant to be merged. It shows what a real project commits when it manages its schema
with `@storyblok/schema` and ships breaking changes with content migrations.

The schema in `src/schema/` was generated by `storyblok schema init` from a realistic, long-lived
website space: 177 blocks, 35 datasources and about 4,000 stories. Each breaking schema change since
then came with a typed content migration in `.storyblok/migrations/`.

## Workflow

```sh
# 1. Change blocks in src/schema/
# 2. Preview the schema diff
pnpm schema:diff
# 3. Push it; breaking changes generate a typed migration and a .before.ts snapshot
pnpm schema:push
# 4. Edit the generated migration, then check it
pnpm test:types
pnpm migrations:apply --dry-run
# 5. Apply it to the space and commit
pnpm migrations:apply --publish published
pnpm migrations:list
```

## Migrations

| Migration                                     | Ops                                    | Stories |
| --------------------------------------------- | -------------------------------------- | ------- |
| `20261029132727-rename-teaser-to-excerpt`     | `renameField` ×2                       | 478     |
| `20261029133458-trim-quote-names-and-roles`   | `alterField` ×2, value-only            | 101     |
| `20261029134313-split-quote-full-name`        | `splitField` with `merge`              | 714     |
| `20261029135828-rename-changelog-entry-v2`    | `renameBlock` of a content type        | 58      |
| `20261029141150-rename-twitter-to-x`          | `renameField` ×2                       | 147     |
| `20261029141206-normalize-hero-headline-size` | `alterField`, inside `enterprise_page` | 15      |
| `20261029142718-split-metric-value`           | `splitField`, refuses one story        | 31      |

`split-metric-value` refused one story whose `metric` value (`"CX "`) holds no amount, so its
`metric` blocks still hold `value`.

The run journal (`.storyblok/migrations/.journal/`) stays on the machine that applied the
migrations, so a fresh checkout lists all seven as pending.
