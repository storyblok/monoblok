# 🐛 [Bug]: RichTextResolver produces shattered links when text is styled

### Package

@storyblok/richtext (Rich Text Renderer)

### Bug Description

Hi, we ran into the following problem when it comes to give a part of a linked text a visual
accentuation (which is relevant for UI reasons). For example a link to a page domain.com with text
like "Follow us to our **new** page".

The resolver's output are shattered a-Tags where each is linked to domain.com: 

- an a-tag with text "Follow us to our ",
- an a-tag with text "new " (bold style included) and
- an a-tag with text "page"   For SEO-reasons it is relevant to render it properly so there is only
  one a-tag containing (styled) spans for each part of the text.

Kind Regards Elmar

### Steps to Reproduce

- write some short text
- create a link on that text
- style some words in bold oder italic

(Issue also occurs when step 2 and 3 are switched)

### Expected Behavior

One a -tag is rendered where each individual styled text part is wrapped in a span element

### Actual Behavior

For each styled fraction of a text link an a-tag is rendered pointing to the same target URL
