An Angular app with server-side rendering that renders Storyblok stories with `@storyblok/angular`
(https://github.com/storyblok/monoblok/tree/main/packages/angular). Register every new block in `src/app/storyblok.components.ts`.

- Angular: https://angular.dev/llms.txt

`npm run dev` serves https://localhost:4200. The Visual Editor needs HTTPS.
